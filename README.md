# Transactions Exercise

A starter project for Qonto's iOS live coding interview. It displays a list of transactions fetched from a remote API.

## Before the interview

Please take time to prepare beforehand:

1. Clone this repository
2. Open `Transactions/Transactions.xcodeproj` in Xcode
3. Build and run on any simulator — the app should launch and immediately crash
4. Make sure you're ready to share your screen during the session


## During the session

You will work with Qonto interviewers on a set of incremental tasks. Please share your reasoning out loud as you work:

- what you are trying to do
- what is unclear
- how you validate your solution
- how you keep the code simple and maintainable

We will pay attention to engineering practices such as architecture, SOLID, KISS, DRY, appropriate design patterns, testing, and product thinking.

## AI usage

You are expected to use AI tools during the session, as you would in a real work situation.

We will pay attention to how you:

- guide the AI with context and constraints
- challenge its suggestions
- validate generated code before relying on it
- make sure the final solution meets the expected quality bar

If you do not have access to an AI tool, please tell us in advance.


## Requirements

- Xcode 26.4+
- iOS 26+ simulator
